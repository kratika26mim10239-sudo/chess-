# Simple  Chess Game

A lightweight, terminal-based chess game written in pure Python. No external dependencies or libraries required—just run it directly in your terminal.

## Features
- **Clean Board Layout:** Uses standard 8x8 grid notation (`a1` to `h8`).
- **Standard Pieces:** Supports White (UPPERCASE) and Black (lowercase) pieces.
- **Turn-based Gameplay:** Automatically alternates turns after each valid move.
- **Easy Input Format:** Simple square-to-square coordinate inputs (e.g., `e2` then `e4`).

## How to Run

1. Make sure you have Python installed on your system.
2. Clone or download this repository.
3. Open your terminal or command prompt in the project folder.
4. Run the game using:

```bash
python main.py
